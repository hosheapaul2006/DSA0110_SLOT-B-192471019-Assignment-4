PURPOSE OF THE ASSIGNMENT 
This assignment evaluates your ability to design a class hierarchy before writing its code, so 
that common behaviour is written once and new kinds of objects can be added without 
changing working classes.

Interpret the Requirement → Identify Is-a and Has-a Relationships → Design the Hierarchy 
→ Decide Access → Implement → Trace Construction → Challenge → Refine
